## ntfy-desktop (design reference)

NtfyTray is a PowerShell re-implementation modelled on
[simoneferrari/ntfy-desktop](https://github.com/simoneferrari/ntfy-desktop) (C#/WPF, master at
commit 8fcd2e0, July 2026). No C# source was copied. The following ideas were ported by
hand into PowerShell: the reconnect backoff schedule, the timestamp `since=` cursor, backfill
detection by connect time, the catch-up summary toast, the http(s)-only URL allow-list, the
priority-to-toast mapping (urgent scenario + looping alarm, attribution badges), the
emoji-prefixed toast title, DPAPI token storage, HKCU AppUserModelId registration, the
HKCU Run autostart entry, notification pause with connections left open, active hours, and
the tray status colours. Its licence notice:

## ntfy

[ntfy](https://github.com/binwiederhier/ntfy) (Apache-2.0 / GPLv2) is the server and protocol
this client talks to. No ntfy code is included; the JSON stream format, `since=`, `poll=1`,
`/<topic>/auth`, priorities, tags, click and actions follow the
[ntfy docs](https://docs.ntfy.sh/subscribe/api/).
